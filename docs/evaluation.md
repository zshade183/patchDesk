# PatchDesk 6 题代码修复评测

这是 repair-v1 的历史记录。当前评测入口运行扩展后的 repair-v2。
测试日期为 2026-11-24。环境为 Windows、Python 3.12.7、git version 2.39.0.windows.2。
题集版本为 repair-v1。在线实验配置的模型 ID 为 `deepseek-flash`。

## 实验设计

使用六个合成的 Python 缺陷题。每次任务重新生成 Git 仓库，题目文字、原实现和验收断言固定。原仓库必须通过回归测试，并因预期缺陷无法通过独立验收，才会进入实验。

模拟离线基线每题运行一次，使用固定工具动作验证 Git、修改、补丁和测试链路。真实模型每题运行两次，每次从新副本开始，不继承上一轮补丁。两种模式使用相同的回归和独立验收。独立验收断言不写入任务仓库。

| 题目 | 独立验收覆盖 |
| --- | --- |
| 分页 | 尾页不足一页、输入短于页长和空列表 |
| 去重 | 整数及字符串去重后的首次出现顺序 |
| 均值 | 空列表返回 None、正负数及单元素 |
| 标签规范化 | 去空白、小写、空标签过滤与有序去重 |
| 闭区间重叠 | 端点相接、相同单点及分离区间 |
| 跨文件折扣 | 结算层传递会员标记、定价层正确打折及整数截断 |

## 实测结果

| 实验 | 解决数 | 回归通过数 | 独立验收通过数 | 耗时中位数 | 平均轮数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 离线基线 | 6/6（100.0%） | 6/6 | 6/6 | 5.14 秒 | 4.33 |
| 真实模型 | 12/12（100.0%） | 12/12 | 12/12 | 11.43 秒 | 4.83 |

解决一题需要同时满足正常结束、生成非空补丁、回归通过和独立验收通过。回归通过数统计所有运行，原实现也能通过回归，因此独立验收和补丁是成功判定的一部分。耗时从创建测试仓库开始计，到任务验证返回为止。在线轮数统计执行器报告的模型调用，服务客户端内部的 HTTP 重试不另计。离线轮数对应脚本动作。

| 题目 | 真实模型第 1 次 | 真实模型第 2 次 |
| --- | --- | --- |
| 分页 | 通过 · 15.27 秒 · 6 轮 | 通过 · 9.50 秒 · 4 轮 |
| 去重 | 通过 · 15.55 秒 · 5 轮 | 通过 · 10.23 秒 · 4 轮 |
| 均值 | 通过 · 9.17 秒 · 4 轮 | 通过 · 11.20 秒 · 5 轮 |
| 标签规范化 | 通过 · 8.31 秒 · 4 轮 | 通过 · 11.67 秒 · 5 轮 |
| 闭区间重叠 | 通过 · 10.27 秒 · 4 轮 | 通过 · 12.50 秒 · 5 轮 |
| 跨文件折扣 | 通过 · 14.28 秒 · 6 轮 | 通过 · 14.77 秒 · 6 轮 |

跨文件折扣题的三个成功副本均修改了 `logic.py` 和 `pricing.py`。逐份直接导入两个公开接口复核，均通过独立验收。

## 复现与边界

```powershell
.\.venv\Scripts\python.exe -X utf8 -m patchdesk.benchmark
.\.venv\Scripts\python.exe -X utf8 -m patchdesk.benchmark --live --repeat 2 --model deepseek-flash
```

逐次 JSON 汇总位于 `.runs/benchmark-repair-v1-scripted.json` 和 `.runs/benchmark-repair-v1-model.json`。汇总中的 run_id 可关联每次的补丁、工具记录及测试输出。

本实验评估小型 Python 代码修复链路。六种缺陷各自只有一个初始实现。在线实验的 12 次运行来自六道重复题，可用来观察重复结果，不能视为 12 道不同题，也不代表真实项目的总体成功率。在线耗时包含当次网络和服务时延。
