# PatchDesk 12 题代码修复评测

这是 repair-v2 的历史记录。当前评测入口运行 [40 题版本](evaluation-v3.md)。

题集版本为 repair-v2。测试环境为 Windows、Python 3.12.7 和 git version 2.39.0.windows.2。在线配置的模型 ID 为 `deepseek-flash`。

## 题集与判定

保留分页、去重、均值、标签规范化、闭区间重叠和跨文件折扣六道题，新增以下六道。

| 新增题目 | 独立验收覆盖 |
| --- | --- |
| 稳定排名 | 分数降序，同分保持输入顺序 |
| 严格日期 | 闰日、非法月份、前导零、尾随字符和年份 0000 |
| 原子库存更新 | 后续条目缺货或库存不足时，先前条目的库存维持原值 |
| 缓存键冲突 | 分隔符位于不同元素、空列表、空字符串与 Unicode |
| 跨文件配置优先级 | 保留 0、False 和空字符串，跨模块读取端口，输入字典保持原样 |
| 合并预订区间 | 乱序、嵌套、端点相接与原输入保持不变 |

每次运行都创建新的合成 Git 仓库。进入修复之前，原实现必须通过回归测试并触发独立验收失败。一轮实验计为解决时必须正常结束、有补丁、回归通过且独立验收通过。独立验收断言位于评测程序中。

## 复现

```powershell
.\.venv\Scripts\python.exe -X utf8 -m patchdesk.benchmark
.\.venv\Scripts\python.exe -X utf8 -m patchdesk.benchmark --live --repeat 2 --model deepseek-flash
```

逐次记录位于 `.runs/benchmark-repair-v2-scripted.json` 和 `.runs/benchmark-repair-v2-model.json`。各行的 run_id 对应逐次报告、补丁和工具调用记录。

每道题只有一个合成初始实现。24 次在线运行来自 12 道题各跑两次，用于描述本题集的重复表现。结果受题目组成、模型服务和当次网络条件影响。
